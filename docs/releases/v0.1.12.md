# STIX v0.1.12 Release Readiness

Date: 2026-07-26

## Scope

This release keeps the Floci-backed local STIX stack running while tightening dashboard UI wiring and the policy/approval service paths that the UI depends on.

Doctrine/FDE remains an external governed operating module. STIX Fabric is still evaluated independently from Doctrine observer metadata.

## Product Changes

- Bumped live STIX versions to `0.1.12`.
- Wired the dashboard Policy Simulator through the shared dashboard API client instead of a hardcoded `http://localhost:3001` fetch.
- Added a React Query authorization mutation that refreshes dashboard stats, evidence, and approvals after simulator runs.
- Added Policy Simulator controls for detection signals: PII, PHI, PCI, and Secrets.
- Added Policy Simulator risk-tier wiring so high-risk tool scenarios send resource attributes and `tool_call.risk_tier` to Enforcer.
- Updated simulator presets so expected decisions match live policy behavior.
- Fixed policy-pack loading so multi-document YAML policy packs load all service-valid documents, not only the first YAML document.
- Fixed policy condition evaluation for `env`, `require_signal`, `require_resource_attr`, `require_actor_attr`, and tenant-match guards.
- Fixed approvals list filtering for `actor_id` and `action` query parameters.
- Added regression tests for multi-document policy loading and condition guard evaluation.
