# STIX v0.1.15

Released 2026-07-26.

## Continued UI Wiring

- Fabric inventory now supports live registration of agents, enforcement points, tool actions, and policy channels through the existing Fabric POST contracts.
- Successful Fabric registration refreshes inventory, graph, statistics, and readiness views.
- Approval cards now route operators through the detail review flow so required roles, justification, and proof-producing reauthorization are not bypassed.
- Governance delegation data is derived from live approval records instead of placeholder approver rows.
- Dashboard, Governance, Approvals, and GitLab views now surface partial API failures and refresh all relevant live queries.
- GitLab Guardian status is resolved from Fabric inventory; unregistered integrations are no longer shown as active.
