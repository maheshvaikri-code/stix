# STIX v0.1.7 Release Readiness

Date: 2026-07-25

## Scope

This release adds computed Fabric and Doctrine readiness to the dashboard. The implementation derives posture from existing Fabric registry APIs instead of adding unsafe execution wiring.

## Product Changes

- Added `dashboard/src/lib/fabric-readiness.ts` as a pure readiness model.
- `/fabric` now renders readiness exceptions and remediation guidance from registry data.
- `/doctrine` now renders a readiness score, G0-G7 gate coverage, control checklist, and missing-control exceptions.
- Added unit tests for Fabric and Doctrine readiness behavior.
- Bumped live STIX versions to `0.1.7`.

## Doctrine Boundary

Doctrine remains a read-only Fabric integration in this release. STIX computes whether Doctrine is represented in the registry; it does not execute Doctrine tools from the dashboard.

The readiness controls are:

- Doctrine runtime registered.
- Doctrine gatekeeper active.
- Doctrine verify action modeled.
- Doctrine checkpoint action modeled.
- Doctrine gold-build channel active.
- G0-G7 gate coverage present.
