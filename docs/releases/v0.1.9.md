# STIX v0.1.9 Release Readiness

Date: 2026-07-25

## Scope

This release adds the `/Doctrine FDE` deployment lane using Floci as a local AWS-compatible backend. It also makes the containerized deployment path complete by adding the dashboard image target and hardening Docker/Kubernetes deployment readiness.

## Product Changes

- Added Floci AWS emulator service to `deploy/docker/docker-compose.yaml`.
- Added dashboard build/runtime target to `deploy/docker/Dockerfile`.
- Added `name: stix` to the Docker Compose project to prevent unrelated Compose orphan collisions.
- Added health-gated Compose dependencies so services wait for Floci, Postgres, Redis, and upstream STIX services before starting.
- Added `.dockerignore` to keep Docker build contexts deterministic and small.
- Pinned Docker image installs to `pnpm@8.12.0` and copied `.npmrc` into the Docker build context for frozen lockfile compatibility.
- Added `scripts/deploy/floci-aws-smoke.mjs` and `pnpm deploy:floci:smoke`.
- Fixed staging and production Kustomize overlays by patching the existing `stix-config` ConfigMap instead of using invalid generator merge behavior.
- Bumped live STIX versions to `0.1.9`.
