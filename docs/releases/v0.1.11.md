# STIX v0.1.11 Release Readiness

Date: 2026-07-26

## Scope

This release hardens the Floci AWS local-emulator deployment lane and corrects the product boundary between STIX Fabric and Doctrine/FDE.

Doctrine/FDE remains an external governed operating module for engineering and deployment execution. STIX Fabric can optionally observe Doctrine metadata, but Doctrine/FDE is not a Fabric runtime component and does not block Fabric readiness by default.

## Product Changes

- Bumped live STIX versions to `0.1.11`.
- Updated Fabric readiness so STIX Fabric can be `ready` without Doctrine/FDE records.
- Changed Doctrine/FDE records to optional observer metadata only.
- Updated the Fabric demo seed so Doctrine observer records are excluded by default and enabled only with `STIX_DEMO_INCLUDE_DOCTRINE=true` or `--include-doctrine`.
- Hardened `scripts/deploy/floci-fde-gate.mjs` with Compose contract validation, local-only Floci assumptions, isolated project-name support, check-only mode, teardown/reset flags, and non-Fabric Doctrine/FDE reporting.
- Hardened `scripts/deploy/floci-aws-smoke.mjs` with deterministic S3-compatible object content, output hashes, bucket/object/list invariants, and a fail-closed guard against non-local AWS endpoints.
- Pinned the default Floci image to `floci/floci:1.5.11`.
- Removed fixed Compose `container_name` values so isolated Doctrine/FDE drills can run under separate Compose project names.
- Changed STIX services to use static dummy AWS credentials in the Floci drill instead of passing host AWS credentials through.
- Updated dashboard and docs to reflect Doctrine/FDE as external operations, not STIX Fabric product scope.
- Upgraded `better-sqlite3` consumers to `^12.11.1` so frozen installs pass on the local Node 24 toolchain.

## FDE Gate Behavior

`pnpm deploy:fde:floci` performs:

- Docker Compose contract validation.
- Optional `--check-only` preflight validation.
- `docker compose up -d --build` by default.
- Health wait for Floci, Postgres, Redis, Core services, Fabric, and Dashboard.
- STIX Fabric product demo seeding without Doctrine by default.
- `GET /api/v1/fabric/readiness` validation.
- Dashboard route smoke for `/`, `/fabric`, and `/settings`.
- Deterministic Floci S3-compatible artifact round trip.
- JSON report writing to `artifacts/deploy/floci-fde-gate-report.json`.
- Optional teardown with `--teardown` and isolated-volume reset with `--reset-volumes`.
