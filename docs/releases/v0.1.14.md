# STIX v0.1.14

Released 2026-07-26.

## Dashboard Wiring

The Fabric console now uses the live service contracts for the operator workflows that were previously partial or inert:

- Dashboard evidence totals, today counts, and chain status come from Evidence APIs instead of a stale `/api/v1/stats` path.
- Evidence export supports filtered JSON, JSONL, and CSV downloads.
- Approval actions submit the configured operator ID, role, and justification and show required-role mismatches before submission.
- API key and operator identity settings restore on reload and are shared across the sidebar and approval workflows.
- Policy create, edit, import, export, enable/disable, and delete controls are connected to Policy APIs.
- GitLab quick actions now navigate to the live Policy, Governance, and Evidence views.
