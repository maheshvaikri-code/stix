# STIX v0.1.10 Release Readiness

Date: 2026-07-25

## Scope

This release turns the Floci `/Doctrine FDE` deployment lane into a repeatable one-command gate. The gate is usable locally and in CI, and it emits structured evidence for release review.

## Product Changes

- Added `scripts/deploy/floci-fde-gate.mjs`.
- Added `pnpm deploy:fde:floci`.
- Added `.github/workflows/floci-fde.yml`.
- Updated `docs/deploy/FLOCI_AWS_DEPLOYMENT.md` with the one-command gate and CI teardown mode.
- Hardened `scripts/deploy/floci-aws-smoke.mjs` so repeated bucket creation does not fail against S3-compatible emulators that return bucket-exists status.
- Bumped live STIX versions to `0.1.10`.

## FDE Gate Behavior

`pnpm deploy:fde:floci` performs:

- Docker Compose config validation.
- `docker compose up -d --build` by default.
- Health wait for Floci, Postgres, Redis, Core services, Fabric, and Dashboard.
- Doctrine/Fabric registry seeding.
- `GET /api/v1/fabric/readiness` validation.
- Dashboard route smoke for `/`, `/fabric`, `/doctrine`, and `/settings`.
- Floci S3-compatible artifact round trip.
- JSON report writing to `artifacts/deploy/floci-fde-gate-report.json`.

CI can run:

```text
pnpm deploy:fde:floci -- --teardown
```
