# STIX v0.1.8 Release Readiness

Date: 2026-07-25

## Scope

This release promotes Fabric and Doctrine readiness from dashboard-only calculation into shared STIX Fabric control-plane logic. The Fabric service now exposes a backend readiness API, and the dashboard consumes it while retaining a local fallback for resilient development views.

## Product Changes

- Added `packages/fabric-types/src/readiness.ts` with shared Fabric and Doctrine readiness builders.
- Exported readiness models from `@stix/fabric-types`.
- Added `GET /api/v1/fabric/readiness` to the Fabric service.
- Added dashboard API client and React Query support for backend readiness.
- Updated `/fabric` and `/doctrine` to prefer the backend readiness report.
- Converted `dashboard/src/lib/fabric-readiness.ts` into a compatibility re-export.
- Added service and unit coverage for the readiness endpoint and shared readiness model.
- Bumped live STIX versions to `0.1.8`.

## API Smoke

Seeded Fabric data returned the expected backend readiness report:

```text
GET /api/v1/fabric/readiness 200
Fabric score: 81
Fabric level: watch
Fabric issues: 2
Doctrine score: 100
Doctrine level: ready
Doctrine registered: true

```

Fabric remained in `watch` because the demo data intentionally leaves production policy-channel posture and high-risk approval coverage incomplete. Doctrine reached `ready` because the demo seed includes the runtime, gatekeeper, verify/checkpoint actions, active gold-build channel, and G0-G7 gate metadata.
