# STIX v0.1.6 Release Readiness

Date: 2026-07-25

## Scope

This release elevates the STIX UI toward the STIX Core plus STIX Fabric product split and wires Doctrine as a registry-level Fabric integration. Doctrine is represented as an agent runtime, enforcement point, tool-action set, and policy channel. STIX does not execute Doctrine tools directly from the dashboard in this release.

## UI And Fabric Wiring

- `/fabric` now includes an animated governance orbit built with `animejs` and `motion`.
- `/doctrine` presents Doctrine gate posture, mapped tool actions, control-plane boundaries, and Fabric inventory status.
- Dashboard sidebar and mobile navigation include Doctrine.
- Dashboard overview tolerates partial Core API availability and surfaces degraded service status.
- Demo seed command:

```bash
pnpm demo:fabric:seed
```

Seed result during release QA:

```text
Agents=4 EnforcementPoints=3 ToolActions=5 PolicyChannels=3
GraphNodes=15 GraphEdges=29
```

## Dependency Decisions

- `animejs@^4.5.0` was added only to `@stix/dashboard` for scoped imperative animation in the Fabric orbit. It replaces hand-rolled animation loops and cleans up via React effect teardown.
- `motion` remains the declarative UI motion layer already used by the dashboard.
- `next` was upgraded to `15.5.21`.
- Fastify service packages were upgraded to Fastify 5-compatible dependency lines.
- OpenTelemetry packages were aligned to current v2/0.221 package families.
- `yaml`, `js-yaml`, `glob`, `undici`, `nodemailer`, `tailwindcss`, `postcss`, `recharts`, and transitive overrides were hardened.
- `.npmrc` now sets `auto-install-peers=false` for deterministic dependency resolution.
